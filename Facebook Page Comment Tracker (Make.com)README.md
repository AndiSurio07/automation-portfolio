This automation monitors new Facebook Page comments in real-time and automatically logs them into a Google Sheet for easy tracking and It was built using Make.com's free plan.

<br>
<b>FEATURES</b>
<li>
Automatically detects new comments on your Facebook Page posts</li>

<li>Logs each comment into Google Sheets with</li>

<li>Date & time</li>

<li>Commenter name</li>

<li>Comment message</li>

<li>Post ID</li>

<li>Post link</li>

<li>Runs in real-time</li>

<li>100% no-code</li>

<li>Works even on Make.com’s free plan</li>

<li>Clean, simple, and practical workflow</li>

<li>Ideal for social media teams, businesses, and customer support </li>

<br>
<b>TOOLS USED</b>

<li>Make.com</li>

<li>Facebook Pages module (Watch Comments)</li>

<li>Google Sheets module (Add a Row)</li>

<li>Facebook Page (with admin access)</li>

<li>Google Sheets (for data logging)</li>
